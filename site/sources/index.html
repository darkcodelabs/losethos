Sources and preservation notes

This project preserves the lore of Terry A. Davis and his operating systems. Preserved by Corian Kennedy. It restores an early chapter of the project that became SparrowOS and TempleOS. The original domain was losethos.com.

The website

The homepage comes from the July 7, 2006 capture selected for this lore project. Its original wording, Courier New typography, white background, underlined title, table layout, and seven screenshots are preserved. The small power control, browser emulator, and these notes are additions.

Recovered from the Terry A. Davis / TempleOS archive: 36 linked historical pages, images, and downloads for the selected homepage, plus 379 files from the later collection. The 2006 homepage is the exact July 7 capture; supporting files use the available capture closest to July 7, 2006. See the 2006 source manifest. For the later collection, each path uses the latest available capture at or before March 30, 2012. Pages therefore reflect different capture dates, shown on each page. The security discussion and three discussion images have not yet been recovered; these archive gaps remain.

Historical scripts, tracking pixels, active embeds, forms, and external image requests were removed. Local links were repaired. The original Windows Media demonstration was converted to MP4 for current browsers. The original OS code and disk were not modified. The homepage represents 2006, while the powered-on computer runs the preserved 2012 release; these are deliberately identified separately.

The operating system

The emulator boots the actual March 19, 2012 LoseThos live CD. Download the preserved disc. This is LoseThos, not a simulated desktop or a renamed TempleOS fork.

At the account menu, User opens after three idle seconds when the original menu is detected. To choose manually, use the arrow keys and Space. Touch controls and an on-screen keyboard are available on mobile devices. The software and its original account selection run inside your temporary computer. There is no website account, server VM, network adapter, saved disk, or shared guest memory. Refreshing or closing the page discards the session. Public download files may be cached by the browser; your guest session is not saved.

The lineage

The TempleOSGit historical source collection preserves HOPPY, J Operating System, LoseThos, SparrowOS, and TempleOS as separate branches. Follow LoseThos, SparrowOS, and TempleOS to explore the code's development. TempleOS.org preserves the later system.

Emulator credits and source

The x86-64 WebAssembly QEMU runtime comes from TempleOSsy, commit 0463da9. Its frontend is not included. This lore project uses its own small browser interface and loads LoseThos in memory.

QEMU is distributed under GPLv2. Corresponding source: the exact QEMU fork revision, together with the build recipe, display bridge, and patches used for this runtime. BIOS images are extracted unchanged from that project's bundled data. See upstream BIOS provenance and licenses.

The runtime needs a current browser with WebAssembly threads, cross-origin isolation, and roughly 2.3 GB of memory. Guest boot speed depends on the visitor's device.
