LoseThos is a free, open source, 64-bit, PC operating system for those who program for
entertainment.  It's not for everyone (just programmers), it's not suitable for professional game
development, and it's not a full operating system... so, it's like a tree house.  It runs everything in
kernel mode, so it's fast (no mode switches), but dangerous.  If you need a security blanket, get lost.

LoseThos has no Linux, GPL or GNU code, so there are no restrictions -- it's public domain.  It's
100% independent, written from scratch, starting from a clean slate.  You'll probably want to duel
boot, since LoseThos has no networking, though you can run LoseThos as the sole operating
system.
