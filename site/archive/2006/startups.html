This operating system is for programmers.  I advise making two
or three partitions on your hard drive, so you can easily fix a
boot problem by booting to another partition and editing the
broken one.  You can use a CD-ROM for this, but it boots a
little slower.  (I'm spoiled.)  

Linux's LILO boot loader will allow you to boot from one of many
partitions.  I did that with my other computer.  My current
computer came with a recovery disk and doesn't let me
repartition.  I got lucky, though, because it allows booting to
a recovery partition and I tricked-it.  (If you're wondering why
LoseThos marks a partition as "FAT" type instead of a unique
file system ID for LoseThos, it's because the recovery partition
trick only works if it's marked as FAT.)

You might need to use the AddDrives() command if you boot from a
CD and wish to fix a hard disk partition.  If you use the
LTCD.ISO image, login as USER and type "AddDrives" at the
command line.  Once you get proficient enough with LoseThos, you
can create custom bootable CD-ROMs with drives already added.
