Place the following in your HOME/ADAM3.CPZ file.  You might have to shift things
around to meet dependencies.  I did not include this feature in the O.S. because it is
based on personal preference.  It belongs in your own account customizations.  
When doing stuff for myself, I cut corners on little things.

To get a screen shot to another operating system, you must burn a CD-ROM.  I have
one CD-ROM drive which works perfectly and I have one which can burn a CD that
LoseThos can read, but not Windows.  It sucks not having documentation.

void MyScreenShot()
{
    I1 *st=CurDir,*st2;
    LTDirEntry *tempm;
    U8 cnt=0;
    Cd("::/TEMP/ScreenShots"); //"::" specifies the boot drive
    tempm=FindFiles("*.BMP");
    while (tempm) {
    cnt++;
    tempm=tempm->next;
    }
    st2=MSPrintF("SCRN%04d.BMP",cnt);
    CaptureScreen4(st2); //4 bit color
    Free(st2);
    Cd(st);
    Free(st);
    Beep;
}
