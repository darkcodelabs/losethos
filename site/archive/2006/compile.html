To install to a hard disk, first get a partition bootable with some other
operating system.  Next, boot to the Live LoseThos CD-ROM and test if the
hard disk is recognized by LoseThos.  Select the "USER" menu option, get
to the command prompt and type:

T:>AddDrives;

When prompted by AddDrives(), enter 'C' for the base drive letter, and
enter '3' for the controller type, followed by '3' for port, and finally
'0'.  Then, hit "ENTER" to exit AddDrives().  Check the report of
partitions to see if 'C' was listed.  If you are installing to a hard disk
with multiple partitions, you should see a 'D' drive or 'E' drive, etc.
listed.  If this is the case, you're good to go.

Boot the CD-ROM again and enter "INSTALL" and follow the instructions.  
You'll have to reenter the AddDrives() data twice during the process.  If
you are installing to 'D' or 'E', you still enter 'C' for the base
partition of the drive, but select 'D' or 'E' when it asks what partition
to format or install to.  If you enter a wrong letter, you'll destroy data
on other partitions.  I use Linux's LILO on one computer to manage booting
and on my other computer I was fortunate enough to have a factory recover
partition that is bootable.

I haven't tested this a lot, so good luck.  I wouldn't recommend doing
this on hard disks with important data on other partitions.
