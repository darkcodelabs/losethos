LoseThos is a 64-bit, free, open source, PC operating system.
It's under a BSD license but contains no BSD code.  I wrote LoseThos 100% from scratch.  
The license is a known quantity so I chose it.  It permits almost everything and just disclaims
liability.

LoseThos does not use fancy CPU features of the x86 like virtual memory and privilege levels,
keeping it as simple as possible and boosting performance.  It's for fun and games and
tinkering and learning.  It can swap a task in half a microsecond!  Linux is too complicated for
programmers to understand and tinker with... might as well not be open source.  LoseThos
uses minimal abstraction and layering so you don't have to dig deep through calls to get to the
hardware.  Have you ever tried to locate hardware I/O instructions in Linux?

As part of minimal abstraction, LoseThos is wedded to the x86 architecture, using x86
terminology for everything, like "Fs->" for the FS segment register and "Tss" for task records.  
Many Intel assembly language instructions in C are named based on the x86 architecture.  It
has no 32-bit legacy bloat and can unleash the full power of a modern system.  It supports
MultiCore and can support more than 4Gig of RAM.  

It uses just the hardware pretty-much common to all modern 64-bit IBM PC compatibles, so
there is not the redundancy of multiple drivers, compatibility issues and horrifically complicated
code for multiple platforms, like with Linux.
