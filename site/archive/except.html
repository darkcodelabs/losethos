When you throw an exception, you do not use a special class.  throw(...)
is a variable parameter count function and you can pass values to the
handler.  In general, variable parameter functions in LoseThos use two
variables--argc and argv[], similar the main{} routine in C, except all
paramters are 64-bit generic integers.  

With exceptions, the argc and argv[] from the throw(...) are obtained
from the task structure accessed off the Fs pointer.  To indicate that a
exception has been caught, set Fs->catch_except to TRUE.
