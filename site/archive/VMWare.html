LoseThos Can Now Run in a Virtual Machine

1) Download the latest 64-bit version of VMWare.
Download VMWare
2) Set the CD-ROM to the file, LTCD.ISO.  
Select "Other 64-bit Operating System".  
Set memory to 512 Meg or more.

3) Play the virtual machine and log-in as "VMWareQuickInstall".  If a quick install doesn't work, try a
manual install.  (VMWareQuickInstall feature was just added 12/15/09.)

Note: HD Audio does not work under VMWare but should on real hardware.

Note: With VMWare there is no way to transfer files into or out-of LoseThos, unless you want to burn a
CD.  A non-virtual installation on an actual hard drive partition allows transfers to a dual booted other
operating system by way of a shared FAT32 partition or the LTZ program.  On my machine, CD-ROM
burning doesn't work in VMWare.
