                    The LoseThos 64-bit PC Operating System

                       Download LoseThos V7.07 (5.74 Meg)
                             Burn a CD and boot it.
                                   It's Free!

LoseThos is a 64-bit, multicored, multitasking, 100% open source, public domain, 
ring-0-only, single-address-map operating system for the IBM PC.  It requires a 
64-bit x86_64 CPU and 512+ Megs of RAM.  It does not have GPU acceleration, so I 
limit it to 640x480 16 color graphics.

LoseThos will run natively, either stand-alone or dual booted.  The easiest way 
to dual boot is to install on a 2nd hard drive and select which to boot with the 
BIOS.  Use LoseThos' installer to install onto a partition.  LoseThos has an 
optional master-boot-record boot-loader and can partition a drive if necessary.  
YOU CAN'T COMPILE WITH OTHER COMPILERS.  Use InstallBoot() to make, if you like.

The vision for LoseThos is a 64-bit Commodore 64 that's a thousand times faster 
than the original and has a shell that is C/C++ instead of BASIC.  It's for 
recreational programming.  The reason you would pick LoseThos over Linux is that 
it is only 129,050 lines of code, so you can easily tinkering.  LoseThos is a 
secondary operating system you will use in additional to Windows or Linux 
because LoseThos does not have networking.

This is not a good-for-teaching-only OS.  LoseThos is naughty, ring-0-only, the 
same way red-necks are naughty.  The name was inspired by the scene in the 
movie, Platoon, where Elias says to Chris, "S**tcan this and this...", referring 
to dorky standard issue equipment.  Red-neck, freak or nerd, if you are 
interested in assembly language, that's probably the best correlation with 
LoseThos being right for you.  This is not an asm-only OS, however, because 
that's just silly. 

This is not an amateur OS for old, pathetic hardware.  I was a paid operating 
system developer for Ticketmaster at age 20 in 1990 and have worked on LoseThos 
full-time for 8.2 years.  Unlike Linux which is, technically, just a kernel, 
LoseThos includes a complete tool chain -- 64-bit kernel, 64-bit compiler, 
assembler, editor, graphics library, document framework and tools such as grep 
and merge.  It never executes code I did not write except a couple BIOS calls 
during boot.  However, it has no networking and, with no protections, will crash 
on bugs or misuse.

I have a B.S.E. in computer systems engineering (embedded system hardware and 
software) and a M.S.E. in electrical engineering (control systems) from Arizona 
State University.  Everybody knows electrical is higher in the engineering 
pecking order than CS because it requires real math ;-)  I'm a rocket scientist, 
though not a very good one.  Download SimStructure (key: A18-W50-U50), an 
application for Windows, if you want to play with my physics simulator.  It has 
my first C compiler built into it, for use in the control systems.  It's an 
interpretor, but LoseThos has a true compiler.  Hats off to the MATLAB creators, 
by the way.

I have many years experience as an embedded system programmer working in 
assembly language on bare metal for various architectures.  LoseThos is a lot 
like an embedded OS.
