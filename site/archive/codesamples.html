If the code looks funny, that's because LoseThos has it's own 64-bit C/C++
compiler and x86 assembler.  Source code is not just ASCII, it has graphics,
super/sub scripting, links and colored text.

I8  means 8 byte (64-bit) signed integer.
U4 means 4 byte (32-bit) unsigned integer.

The assembler opcodes have slightly been modified, but it's for an ordinary
x86_64 computer.
