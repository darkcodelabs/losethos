• LoseThos only compiles with it's own compiler, not gcc.

  • If your hard drive size is reported too big, you probably have the correct 1st base
    port number and an incorrect 2nd base port number.  Try HintATA().

  • LoseThos will not boot from USB devices such as memory sticks or external drives.  

  • Mouse wheels mostly don't work.  I have a real-life PS/2 mouse with a working
    wheel.

  • If you have no sound, comment-out #include "HDAudio" in your HOME/Adam3.
    APZ file to revert back to PC Speaker.  Run /LT/Opt/Sound/HDConfig.APZ and
    place the program it creates into your start-up scripts.  You might have to alter
    /LT/Opt/Sound/HDAudio.APZ.  Look at http://download.intel.
    com/standards/hdaudio/pdf/HDAudio_03.pdf.  For microphones, I had to change
    amplifier gains in my HOME/HDAudioCfg.APZ file by hand.  You need to become
    an expert on the HD Audio specification, I guess.

  • If you are interested in qemu, the settings are

    qemu-system-x86_64 -m 512 -cdrom /tmp/LTCD.ISO -boot d

    It's crappy compared to running on real hardware.

  • Booting with grub:  You can't just copy files and boot, use the install wizard when
    you boot the CD, or run the LoseThos command InstallBoot() to compile the kernel
    and modify the partition's boot record, telling it where to load the kernel from.  Make
    entries in grub.conf like this, if you use grub:
    # Tip: the (hd0,n) numbers are one less than sda numbers.

    title                Windows XP Professional x64 Edition
    root                (hd0,0)
    savedefault
    makeactive
    chainloader        +1

    title                LoseThos Drive D
    root                (hd0,4)
    chainloader        +1

    LoseThos has a master boot record boot loader if you do not wish to use grub.  
    Call InstallMasterBoot().

  • I/O Port Numbers for Hard Drives and CD-ROM's:  Look in Windows System
    Information under I/O ports.  You'll need two hex numbers for each hard drive and one
    for CD-ROMs. The first number in the pair must be a chunk of at least 8 ports; the
    second, a chunk of at least 4.  Use trial and error to figure-out unit number -- 0 or 1.
