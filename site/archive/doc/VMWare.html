VMWare and LoseThos

Virtual Machines offer a safe way to quickly test drive LoseThos without the 
trouble of repartitioning your hard drive.

1) Download the latest 64-bit VMWare.

2) Set the CD-ROM file to LTCD.ISO.

3) Select "Other 64-bit operating system".

4) Set memory to 512 Meg or more.

5) Play the Machine.

6) When LoseThos boots, click "VMWareQuickInstall".


Note:

* There is no way to transfer files into or out of a VMWare installation, except 
by CD-ROM and my CD-ROM will not burn under VMWare.  You'll want a real, dual 
booted install on your hard disk, eventually, where you can use a shared FAT32 
partition to transfer files.

* HD Audio does not work in VMWare.
