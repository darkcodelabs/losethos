The LoseThos IBM PC Operating System
x86_64, preemptive multitasking, multicore, open source
I come from an embedded systems background.  In our school we were graded on a curve
based on code size.  I can bloat it if you'd like that better.

LoseThos is like a 64-bit embedded OS for IBM PC's.  Nervous about no memory
protections?  You'd freak if you knew how many embedded devices operate just fine with no
protections.  Don't write programs that malfunction.  At the worst, you reboot.  Takes 2
seconds.

It's a live CD so you can test drive or install.

Lite version includes:
  • 64-bit x86 Kernel with Multicore support
  • 64-bit Compiler/Assembler (Yes, wrote it myself.)
  • 64-bit pointers.  All tasks on all cores run with physical address map with full access to
    all locations at all times.
  • Highest CPU privileged mode at all times.  No off-limits instructions. No mode changing
    penalties.  What?  You need a nanny?
  • Switches tasks in half a microsecond.
  • CD/DVD reading and writing, ISO9660 file system
  • 640x480x4 bit VGA Graphics
  • Boot loaders for CD-ROM or hard disk
  • Keyboards & Mice
  • Hard Drive, Support for FAT32 and LoseThos native file systems, File compression
  • Graphics Library
  • Tools/Utilities
  • Demos and Documentation
  • Some games
  • All source code included... Seriously!  Including compiler!  Only 100,000 lines of code!

LoseThos never executes code not written by me except a couple BIOS config calls.  It's
100,000 lines of public domain code with no GPL restrictions.

The full version is 19.7 Meg and costs $19.95.  It includes:
  • Dictionary with vocabulary quiz game
  • Bible with lots of hymns
  • Music program for making songs, jukebox for playing them
  • X-Caliber game
  • Span, bridge building game
  • Programs for uncompressing LoseThos files from Windows or Linux
